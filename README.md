# FEUP - AED PROJECT II - AirTuga

Repository for the second project of the [Algorithms and Data Structures](https://sigarra.up.pt/feup/pt/ucurr_geral.ficha_uc_view?pv_ocorrencia_id=520316) course, at [FEUP](https://sigarra.up.pt/feup/pt/web_page.inicial).


## Project Goals
The main goal of the project is to develop a robust flight management system for an air travel network capable of:
- Check existent flight options from an airport;
- Check existent flight options from a Flight Company;
- Calculate the best flight option from a determinated airport/city to another airport/city;
- Calculate the best flight with X stops;

## Project Highlits
Some of the best features in the project:
- Best flight choice with 3 different options of input - airport, city, geolocation;
- Best flight option with filters;
